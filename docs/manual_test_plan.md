# Manual Test Plan — Lenny Growth Assistant

## Prerequisites
- App running: `docker-compose up` or local dev servers
- Transcripts indexed: click "Index Transcripts" in sidebar or POST `/api/v1/ingest`
- Ollama running with `ollama serve` and `llama3.2` model pulled

---

## 1. Health & Setup

| # | Action | Expected |
|---|--------|----------|
| 1.1 | GET `/api/v1/health` | `{"status": "ok"}` |
| 1.2 | GET `/api/v1/ready` | `status: ready`, correct `active_model` shown |
| 1.3 | GET `/api/v1/ingest/status` | `chunk_count > 0` after indexing |
| 1.4 | Open frontend at `http://localhost:5173` | App loads, sidebar visible |
| 1.5 | ModelBadge in header shows correct provider/model | Matches `LLM_PROVIDER` in `.env` |

## 2. Session Management

## 7. Error & Resilience

| # | Action | Expected |
|---|--------|----------|
| 7.1 | Stop Ollama (`Ctrl+C`), send a message | Error message shown in chat bubble, not crash |
| 7.2 | POST to invalid session UUID | 404 JSON error with clear message |
| 7.3 | Send empty message via API | 422 validation error |
| 7.4 | Stop PostgreSQL, start backend | Backend logs DB error, `/api/v1/ready` returns `degraded` |
| 7.5 | Send very long message (8000 chars) | Accepted and processed |
| 7.6 | Send message > 8000 chars | 422 validation error |
